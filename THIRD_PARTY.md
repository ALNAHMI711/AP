No third-party source code is copied into this starter. Candidate links and initial notes:
- Freqtrade: https://github.com/freqtrade/freqtrade — GPL-3.0; assess obligations before distributing combined or derived works.
- Hummingbot: https://github.com/hummingbot/hummingbot — Apache-2.0; preserve notices if code is reused.
- CCXT: https://github.com/ccxt/ccxt — verify current package license and terms before adoption.
- Freqtrade strategies: https://github.com/freqtrade/freqtrade-strategies — review each strategy and its license individually.
- Binance trading bot: https://github.com/chrisleekr/binance-trading-bot — security documentation flags plaintext credential storage; do not deploy unchanged.
- GitLab Spot bot: https://gitlab.com/AndreyPopov/spot-trading-bot — README indicates testing status; GPL-3.0-or-later.

Recheck current license files, transitive dependencies, notices, source provenance and security advisories before copying code or distributing a derivative.
