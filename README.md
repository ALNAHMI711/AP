# ALNAHMI Trading Console

واجهة تداول عربية RTL ومتجاوبة للهاتف والكمبيوتر. هذه النسخة **واجهة أولية فقط** ولا تتصل بمنصة تداول ولا تنفذ أوامر.

## تشغيل المعاينة
افتح `web/index.html` في متصفح حديث. لا حاجة إلى build tools.

## الموجود حالياً
- لوحة تحكم عربية داكنة ومتجاوبة.
- أقسام الأسواق والاستراتيجيات والصفقات.
- نماذج منفصلة لحسابات التداول ومزودي البيانات/الذكاء الاصطناعي.
- صفحة مخاطر وسجل توضيحي.
- وضع LIVE معطّل ولا يوجد حفظ أو إرسال لمفاتيح API.
- الأرقام والصفقات المعروضة افتراضية بالكامل.

## قرار المحرك المقترح
- **Freqtrade** مرشح المحرك الأول بعد فحص التوافق والالتزامات القانونية: https://github.com/freqtrade/freqtrade (GPL-3.0).
- **Hummingbot** بديل لبعض الاستراتيجيات والموصلات: https://github.com/hummingbot/hummingbot (Apache-2.0).
- **CCXT** مرشح طبقة توحيد APIs بعد مراجعة الترخيص والتوافق: https://github.com/ccxt/ccxt
- https://github.com/chrisleekr/binance-trading-bot مفيد للأفكار فقط؛ وثيقة SECURITY لديه تشير إلى تخزين أسرار بنص واضح ومصادقة إدارية محدودة، فلا يستخدم كما هو.
- https://gitlab.com/AndreyPopov/spot-trading-bot مرشح للفحص الإضافي؛ وصف المشروع يشير إلى أنه قيد الاختبار وترخيص GPL-3.0-or-later.

هذه مراجعة أولية للمستودعات والوثائق وليست تدقيقاً أمنياً كاملاً أو إثباتاً للربحية. لا ننسخ مشروعاً كاملاً قبل مراجعة كل ترخيص واعتمادياته.

## المعمارية المقترحة
1. واجهة مستقلة (يمكن نقلها لاحقاً إلى React/Next.js).
2. Backend موثق وآمن (FastAPI) للمصادقة والإعدادات وتنفيذ الطلبات.
3. محرك تداول يعمل كخدمة منفصلة خلف واجهة API موثقة.
4. PostgreSQL، وRedis اختياري للمهام.
5. Docker Compose، HTTPS، health checks، نسخ احتياطية.
6. خزنة أسرار مشفرة على الخادم؛ لا ترجع الأسرار للمتصفح بعد حفظها.
7. Backtest ثم PAPER/DRY_RUN أولاً؛ LIVE مقفول افتراضياً.

## قبل ربط حساب حقيقي
- لا تسمح بصلاحية السحب لمفاتيح التداول.
- قيّد المفتاح بعنوان IP الثابت للخادم عندما تدعم المنصة ذلك.
- تشفير مفاتيح API على الخادم باستخدام مفتاح تشفير خارج قاعدة البيانات.
- لا تسجل الأسرار في logs ولا تحفظها في المتصفح.
- تحقق من الرصيد والدقة والحد الأدنى للأمر والانزلاق وحدود الطلبات.
- طبّق حدود الخسارة والمخاطرة في الخادم ولا تسمح للـ AI أو الاستراتيجيات بتجاوزها.
- أضف اختبارات المصادقة والصلاحيات وIDOR وإعادة التشغيل ومصالحة الأوامر، ثم فحوصات dependencies/secrets/SAST/container في CI.
